# Developer Portfolio

A single-page developer portfolio built with Next.js (App Router), TypeScript, and Tailwind CSS. 

## Overview & Key Features

- **Hero / Intro Section** — Displays profile details, location, bio, contact links, and a highlighted PDF Résumé action button.
- **Tech Stack Marquee** — An infinite-scroll marquee showcasing core technologies and developer tools.
- **Featured Work** — A responsive grid featuring:
  - Collapsible list view showing top featured projects with an inline top-right **View all / Show less** toggle.
  - Smooth entrance and exit layout animations powered by Framer Motion.
  - Project cards featuring image previews, descriptions, external links, and technology tags.

## Tech Stack

- **Framework:** Next.js 15 (App Router, TypeScript)
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
